{% comment %} A trend chart of one test's results: the results in the order their reviews were signed, the center line and limits of each limits version over the results it judged, the specification limits, and the flagged results (a diamond for an alert, filled while not evaluated, outlined once an evaluation covers it; a square for a result out of specification). Rendered by {% trend_chart %} ({% load ui %}); the geometry and every word come from trending.plot.geometry. This is the one data drawing of the application, so it is the one template besides the icon that writes SVG (tests/test_icons.py). The SVG is an image with a name and a caption; the results table beside it on the page holds the same values for keyboard and assistive technology. Each mark keeps its words in a , shown on hover. Below its minimum width the drawing scrolls sideways in a focusable region, like a wide table.
