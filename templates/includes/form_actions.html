{% comment %} A form's action row (docs/ui-standards.md, Lists and forms): destructive action first, then Cancel (btn-link), then the one primary button last. {% form_page %} renders it; a form built by hand ends with it. Rendered by the {% form_actions %} block tag ({% load ui %}); its body is further buttons or links. Parameters: submit_label the submit button's words (default "Save changes") cancel_url where Cancel returns; without it there is no Cancel link cancel_label Cancel's words (default "Cancel") cancel_hook optional data attribute name on the Cancel link, rendered as data- (signature-dialog.js reads data-signature-cancel) destructive truthy when the submit ends or voids something: btn-outline-danger, at the start secondary truthy for a btn-outline-secondary submit no_submit truthy to leave out the submit name, value optional name/value of the submit button (a form with several actions) Body: further buttons, e.g. "Save and add another". The primary stays first in the markup, so Enter submits it, and is shown last (order-last). Usage: {% form_actions cancel_url=cancel_url submit_label="Create draft" %}{% endform_actions %} {% endcomment %}
