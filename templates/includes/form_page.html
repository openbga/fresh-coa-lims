{% comment %} The form shell of a form or action page (docs/ui-standards.md, Lists and forms): form.vr-form, CSRF, the error summary ({% form_errors %}), one required-fields note ({% required_note %}), the sections, and the action row ({% form_actions %}). Rendered by the {% form_page %} block tag ({% load ui %}). The tag's body is the sections: one or more fieldset.vr-form-section, including the form's hidden fields. An empty body renders every field of the form in one section. Do not put {{ form }} in the body: it repeats the error summary. Parameters: form the bound form (required) formset, formset_label child rows, passed to the error summary action target URL (default: this page) method "get" for a step that only chooses what the next page shows (no CSRF token); default post multipart truthy for a file upload note, times appended to the required-fields note no_required_note truthy to leave out the note (a form without required fields) autocomplete_off truthy for autocomplete="off" (signing and credential forms) hook optional data attribute name on the form, rendered as data- dialog for a form inside a record or list page: the words of the button that opens it in the shared form dialog (static/js/form-dialog.js puts the button in its place; without JavaScript the form stays where it is). Also the dialog's title. dialog_size sm, md (default) or lg, as in core/form_surfaces.py cancel_url, cancel_label where Cancel returns (the record when editing, the list when creating) and its words (default "Cancel") cancel_hook optional data attribute name on the Cancel link (e.g. "signature-cancel") submit_label, submit_icon, destructive, secondary, no_submit the action row ({% form_actions %}) id, class optional id and extra classes on the form Parts ({% fill name %} ... {% endfill %}): note the note's extra sentences when they need tags or values (instead of note=) actions further buttons in the action row, shown before the primary Usage: {% form_page form=form cancel_url=cancel_url submit_label="Record result" %}{% endform_page %} {% endcomment %} {% load ui %}
