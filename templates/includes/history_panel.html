{% comment %} A record's history (docs/ui-standards.md): the final panel, "History", with its events newest last as {% history_item %} entries, or an empty state. Rendered by the {% history_panel %} block tag ({% load ui %}). With an empty body each event is an AuditEvent (title event.action|action_label, occurred_at, actor, reason); a body replaces that with the caller's own {% history_item %} loop. Parameters: events the events, oldest first; required even with a body (it decides the empty state) newest_first truthy when events come newest first: they are shown reversed title the panel heading (default "History"); heading_id: default "-heading" count optional text after the title (or a "count" part for markup) class extra classes on the panel collapsible truthy to render it closed, opening on its heading (a record's secondary history) empty_title default "No recorded changes yet"; empty_body: optional sentence Parts: count; footer (e.g. the history's pager). Never inside the shared form dialog: fetched into it (form_dialog, a documented read) it renders nothing, and on the full page it carries vr-page-only, so a form URL opened directly and then shown as the dialog still ends with the form's action row. Usage: {% history_panel events=history %}{% endhistory_panel %} {% history_panel events=receipt_history title="Receipt history" %} {% for entry in receipt_history %}{% history_item title=entry.title at=entry.receipt.recorded_at actor=entry.receipt.recorded_by %}{% endfor %} {% endhistory_panel %} {% endcomment %} {% if not form_dialog %}{% load ui %}{% with items=body %}{% panel title=title heading_id=heading_id class=class|add:" vr-page-only" count=slots.count|default:count collapsible=collapsible %} {% if events %}
    {% if items %}{{ items }}{% else %}{% for event in events %}{% history_item title=event.action|action_label at=event.occurred_at actor=event.actor reason=event.reason %}{% endfor %}{% endif %}
