{% load ui %}{% comment %} Signature manifestations beside a signed record (docs/ui-standards.md, Signing and review): for each electronic signature its signer, meaning, server time and the record revision it binds. Rendered by {% signature_list %} ({% load ui %}) as history wells (ol.vr-timeline) with the vector-pen signature icon. Each item carries data-signature-meaning and data-signature-revision as stable hooks. Parameters: signatures core.ElectronicSignature rows, oldest first subject the record kind the revision belongs to, e.g. "Lot" or "Result" (default "Record") numbered truthy to name the record by its id after the subject ("Result 12 revision 3"), when signatures of several records share the list hash truthy to show the start of the signed content's SHA-256 hash empty sentence shown when there are none (default "Not signed.")
