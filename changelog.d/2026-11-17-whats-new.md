**What's new** at the top right of every page lists the changes to OpenBGA QM LIMS, newest month first and ranked by impact, with what each means for your work and where to find it. A number beside it counts the changes made since you last looked; opening the list clears it for your account on every workstation. A new account starts with no number.

## Technical notes

- New app `whatsnew` (no models, no migration) and page `whatsnew:index` at `/whats-new/`. Each change is one file in `changelog.d/`, which ships with the application; nothing is fetched over the network.
- `CHANGELOG.md` is now generated from `changelog.d/` by `python manage.py changelog`; `--check` fails when an entry is invalid or the file is stale. Do not edit `CHANGELOG.md` by hand.
- The last change a user was shown is the presentation preference `whatsnew.seen`, set by the server the first time a page renders for the user and whenever the list is opened.
- The validation pack's `release-notes.md` is the whole generated `CHANGELOG.md` of the commit.
